# Simple Money — Personal Finance Management App

A responsive personal finance management application built with React, Tailwind CSS, Spring Boot, and MySQL to help users track expenses, manage income, monitor transactions, and gain better control over their finances.

## Overview

Simple Money makes personal finance management simple and accessible. It provides a clean, intuitive dashboard where users can monitor their financial activity, review transactions, and understand their spending habits.

## Features

* **Dashboard Overview** — View total balance, income, and expenses at a glance.
* **Expense Tracking** — Record and monitor daily expenses.
* **Income Management** — Keep track of income and financial activity.
* **Transaction History** — Review recent transactions in one place.
* **Financial Analytics** — Visualize financial data through charts and summaries.
* **Category Management** — Organize income and expenses by category.
* **Responsive Design** — Enjoy a consistent experience across desktop, tablet, and mobile devices.
* **Clean User Interface** — Navigate your finances through a simple, modern dashboard.
